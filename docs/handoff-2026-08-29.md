### 已確認不可用（寫進 baseline 的環境限制）
- **指定視窗截圖需 Herdr 的 Screen Recording 權限**：授權 `/opt/homebrew/bin/herdr` 後，新行程 `CGPreflightScreenCaptureAccess()` 為 `true`，Finder/Ghostty 實際 window capture 已驗證。這仍不代表 MindFlow 新外觀已驗證；需另輪啟動 App 才能取證。
- **Tab（key code 48）無法以任何合成路徑遞送**（SE key code、CGEvent HID/PostToPid、cliclick kp:tab 全試過）→ U4/U5 的 Tab 步驟用右鍵選單/menubar 取代（同一 vm.addChild 路徑），文件需註明。
- **Esc**：對編輯欄無可觀察效果（不提交也不捨棄；欄位仍在、flush 後文字未存）→ U4 預期 FAIL，這就是要的證據。
- **Return 不會提交編輯欄**（新模型裡 Return 是「編輯選中節點」）。
- 拖曳：`cliclick dd/dm/du` 有跑，但 12px 是否遞送未證實（現幾何 N-0006→N-0007 間距 27px，12px 落點在兩節點之間）。用「label 是否翻轉」當 3px=click / 12px≠click 的遞送判準。
