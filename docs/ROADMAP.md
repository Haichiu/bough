## 新候選項目

### 1. 概要括線進階
- 支援跨兩個以上兄弟的範圍（需先有多選或範圍選擇 UI）
- 概要節點化（可掛子主題）——需版面預算支援
- OPML 匯出以自訂屬性攜帶概要

### 2. 圖片附件第二階段
- 節點上直接縮放圖片（拖曳控點）
- 大圖自動降採樣（超過上限時提示縮圖而非拒收）
- FreeMind .mm 的 richcontent 圖片互通

### 3. 版面微調
- 同層節點寬度一致性選項
- 手動位置偏移的視覺提示強化（目前僅靠右鍵重設）

## 已知限制（非缺陷）

- KeyboardMonitor.swift 的 NSEvent 事件監聽會產生一則 Sendable 相關編譯警告——AppKit API 本身的宣告限制，Swift 6 語言模式普及後需改寫（目前 @preconcurrency 已壓制到單一警告）
- SVG 匯出以淺色為基準，不跟隨系統外觀（保證跨平台一致性）
- 魚骨圖匯出 SVG 時連接線以通用貝茲曲線呈現（與畫面的魚骨專屬畫法略有差異）
- 簡報模式下拖放文字／圖片仍可編輯內容（屬刻意保留的輸入通道；⌘Z 歷史已隔離）
- Markdown 匯出概要以 `- ↳ 概要（含…）` 項目呈現；重新匯入時成為一般節點（已記載於 FORMAT.md）

## 防護機制

| 機制 | 防什麼 |
|---|---|
| `scripts/check-ui-coverage.sh`（併入 verify.sh） | 公開 API 沒有 UI 入口的孤兒功能 |
| MindFlowChecks 格式契約測試 | 文件範例與實際解碼行為脫鉤 |
| FreeMind 往返測試 | 匯入↔匯出的資料損失 |
| pre-commit 鉤子 | 未通過驗證的提交 |
