# MindFlow 驗收測試指南

> 針對 v21.x–v25.x 新增功能的快速驗證清單。每項約 30 秒。

## 互動修復驗證（最重要）

- [ ] 快速點擊幾個不同節點 → 應該立即反應，無延遲感
- [ ] 拖曳一個節點到新位置 → 應該流暢跟手，不跳動
- [ ] 在檢閱器捲動長備註 → 地圖不應跟著移動
- [ ] 點擊空白處 → 不應出現任何意外行為

## 概要括線

- [ ] 右鍵節點 → 「加入概要括線（含下一個兄弟）」→ 畫布上出現括線膠囊
- [ ] 點擊括線膠囊 → 檢閱器顯示「概要括線」區塊
- [ ] 輸入概要文字 → 畫布上膠囊即時更新
- [ ] 按「◀ 縮小範圍」「延伸範圍 ▶」→ 括線涵蓋範圍變化
- [ ] 按「刪除這條概要」→ 括線消失

## 批次多選

- [ ] 按住 Shift 點擊多個主題 → 虛線外框標示
- [ ] Shift＋拖曳空白處 → 出現選取框，放開後圈選主題
- [ ] 右鍵任一批次成員 → 看到「批次（N 個）」選單
- [ ] 從批次選單執行上色／刪除 → 正確作用於整批
- [ ] Esc → 批次選取清空

## 圖片附件

- [ ] 把圖片檔拖到主題上 → 主題顯示縮圖、版面自動長高
- [ ] 截圖後貼上（⌘⌥V 或右鍵）→ 同上效果
- [ ] 選取有圖的主題 → 檢閱器顯示縮圖預覽＋「移除圖片」按鈕

## 匯入匯出

- [ ] 匯出 SVG → 用瀏覽器開啟，確認星標／色標／備註提示／超連結正確
- [ ] 匯出 FreeMind (.mm) → 再匯入回來，文字與收合狀態保留
- [ ] 匯出 Markdown → 概要文字以 `- ↳ 概要` 格式出現

## 簡報模式

- [ ] 顯示選單 → 簡報模式 → 只看到中心主題
- [ ] → 或空白鍵逐步揭開 → 地圖自動取景
- [ ] ← 退回上一層 → 正確收回
- [ ] Esc → 完整還原進入前的收合狀態
